## 一、第七棒工作总览

第七棒的核心任务：**UI/UX 重构 + 道路系统重做 + 任务/新手引导系统 + 火把移除 → 建筑光照系统 + 双模式交互 + 快捷键体系**。大幅改变了玩家操作体验。

### 1. UI 布局改造

| 改动 | 位置 |
|------|------|
| 按钮标签化 | `index.html` 底部按钮全部加上文字（🛤️铺路、🏗️建设、📋任务等） |
| 设置/全屏右移 | 从底部移到右上角 `#hud-info` 区域 |
| 人口显示 | `👥 x/y/z`（空闲/人口/住宅），点击弹窗显示详细分解 |
| 暂停指示器 | 顶部居中脉动红色 `⏸ 已暂停`，暂停时底部按钮变为 `▶` |
| 视口坐标 | `viewport-center-display` 实时显示当前视口网格坐标 |
| 挪动模式按钮 | 右下角 `✋ 常时模式` / `🖐️ 挪动模式`（橙色高亮） |
| 任务悬浮窗 | 右侧小浮窗，显示当前任务+进度，新任务红点脉动提示 |
| 炼金/科技/人文 | 炼金需建工业仓储中心解锁，科技/人文常驻 |

### 2. 快捷键体系

| 按键 | 功能 | 文件 |
|------|------|------|
| `Space` | 暂停/继续游戏 | `HUD._bindKeyboard()` |
| `Alt` | 按住显示建筑+道路光照范围（黄色半透明填充） | `MapRenderer._drawLightOutline()` |
| `F` | 切换挪动模式/常时模式 | `MapRenderer.toggleMoveMode()` |
| `Esc` | 退出放置/道路编辑/搬迁/挪动模式 | `MapRenderer` keydown |
| `Tab` | 浏览器默认行为已禁用 | `HUD._bindKeyboard()` |

### 3. 双模式交互系统（挪动模式 / 常时模式）

**常时模式**（默认，按钮 `✋`）：点击建筑 → 详情面板；按住空白 → 平移地图

**挪动模式**（`F` 或点按钮切 `🖐️`）：仅允许拖动建筑，空白区域不响应。放置建筑/铺路时自动强制常时，不可切换。

**建筑搬迁**：详情面板点 `↔️ 移动建筑` → 蓝色虚影跟随 → 点击合法位置放置（`Esc` 取消）

关键代码：`MapRenderer._setupInteraction()` pointerdown 按优先级处理：road edit → placing → relocate → move mode → unit drag → normal。

### 4. 道路系统 v2 重做

道路从第一棒至今经历了三轮大改，当前为最终版：

#### 核心规则

| 规则 | 实现 |
|------|------|
| 批量铺设 | 点击🛤️进入编辑模式（按钮变 `✕ 退出`），单击连续放置，`Esc`/点✕退出 |
| 建造时间 | `config/roads.json` → `buildTime: 1` tick，建造中显示灰色+橙色进度条 |
| 连接性 | 必须紧邻已有道路或**任意建筑**（不仅仓库），`RoadSystem._isConnectedToNetwork()` |
| 拆除限制 | 仅已建成道路可拆，仓库四周至少保留一条邻接道路，`_canRemoveRoad()` |
| 禁建建筑 | `BuildingSystem.canPlaceAt/canMoveTo` 检查道路重叠 |
| 光照 | 每格道路提供 3×3 光照，`TorchSystem.getVisibilityMatrix()` + `MapRenderer._computeLightRects()` |
| 存档 | 不自动生成初始道路，`initFromBuildings()` 已从 `initNewGame` 移除 |

#### 道路系统文件

| 文件 | 作用 |
|------|------|
| `config/roads.json` | 道路类型配置（dirt_path：耗费5石头，1 tick） |
| `src/systems/RoadSystem.js` | 核心逻辑：放置/拆除/连接性/建造进度/存档 |
| `MapRenderer._drawRoads()` | 渲染（含进度条）+ `_updateRoadBuildBars()` 分帧插值 |
| `MapRenderer._updateRoadGhost()` | 绿框/红框预览随鼠标 |
| `HUD._refreshRoadEditMode()` | 按钮状态切换 |

#### 道路依赖建筑（`roadRequired: true`）

以下建筑必须紧邻道路，否则标记 `❌` 失效：
- 工棚（work_shed）
- 木板房（plank_house）
- 狩猎小屋（hunting_hut）
- 渔场（fishing_ground）

失效建筑不提供住宅上限、不产出资源。删路时调用 `checkAllBuildingsValidity()` 全量重检。

### 5. 火把移除 → 建筑光照系统

**TorchSystem 重写**为纯光照计算引擎，不再管理火把实体：

- 建筑提供 `(n+2)×(n+2)` 光照（居中）
- 道路提供 `3×3` 光照
- 可见性矩阵 `getVisibilityMatrix()` 用于迷雾渲染 + 敌人生成
- 开局不生成永恒火把（`base_map.json` 移除 `eternal_torch`）
- 日出/傍晚/深夜迷雾透明度无变化
- 按住 `Alt` 显示所有光照格子（黄色半透明填充+描边）

### 6. 任务系统与新手引导

| 组件 | 文件 |
|------|------|
| 配置 | `config/quests.json` — 7个新手教程任务 |
| 系统 | `src/systems/QuestSystem.js` — 快照机制，进度追踪，存档 |
| 面板 | `src/ui/panels/quest-panel.js` — 任务描述+进度条 |
| HUD | 悬浮窗 `#quest-widget` + 底部📋按钮 |
| 设置 | `启动` 按钮可随时触发教程 |
| 注册 | `main.js` / `PopupManager` / `ConfigRegistry` |

#### 教程任务线

1. **开路先锋** — 修2格路 → 解锁
2. **民以食为天** — 建工棚+狩猎小屋 → 解锁
3. **探索环境时间** — 完成1次探险 → 解锁
4. **快捷键大师** — F/空格/Alt各1次 → 解锁
5. **熟悉更多功能** — 挪建筑/删路/全屏/点人口 → 解锁
6. **科技的力量** — 研究1项科技 → 解锁
7. **人文的智慧** — 研究1项文化政策

#### 快照机制

任务接取时记录基线（道路数、各建筑数量、各类动作计数），进度 = 当前值 − 基线值。接取前的动作不计入。每个新存档都会弹出确认框询问是否开启。

### 7. 其他机制改动

| 改动 | 说明 |
|------|------|
| 入口道路连接 | 探险出发口必须与道路相连才能进入，否则提示"该入口还未与道路相连" |
| 流民系统 | 人口超过住宅上限的部分每3 tick离开1人 |
| 事件通知 | 事件触发时屏幕中央偏上显示 `❗`，1 tick 后消失 |
| 敌人生成 | 仅光照区域6~13格外，删除建筑外缘回退方案；全图回退排除光照区 |

## 三、关键系统依赖关系（第七棒变更后）

```
QuestSystem ──事件监听──→ roadBuilt / buildingComplete / expeditionComplete / moveBuilding
                          roadRemoved / moveModeChanged / fullscreenToggled
                          techResearched / cultureResearched

RoadSystem ──关联──→ BuildingSystem（道路依赖检查、重叠检查）
            ──关联──→ PopulationSystem（铺路占用工人）
            ──关联──→ TorchSystem（道路光照）

TorchSystem ──光照──→ MapRenderer._updateFogTexture()
                      CombatSystem._findSpawnPosition()

BuildingSystem ──checkAllBuildingsValidity──→ 标记 _invalid 建筑
               ──getTotalHousingCapacity──→ 跳过 _invalid 建筑

PopulationSystem ──_onOverflowTick──→ 流民离开（每3 tick）
```
