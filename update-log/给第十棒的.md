### 4. Bug 修复

- 修复首次启动背景音乐丢失：
  - `AudioSystem.playBGM()` 先设置当前 BGM 再计算淡入音量，避免播放成功但音量为 0。
  - 用户首次交互早于音频异步预加载完成时，会在初始化完成后补启动 BGM。
  - 若浏览器仍拦截自动播放，会在下一次真实点击/按键时重试。
- 修复启动后直接进入正式游戏：
  - `ConfigRegistry` 补加载 `config/ui_main_menu.json`。
  - `main.js` 改为先 `boot()` 显示开始菜单，点击“继续游戏”后才读取存档进入游戏。
- 修复 `启动游戏.bat` 打开旧服务页面：
  - 固定使用较少见端口 `18763`。
  - 启动前清理旧端口 `8099` 和当前端口 `18763` 上残留的 `node http-server`。
  - 浏览器等待服务可访问后再打开。
- 修复道路建造进度条异常：
  - 道路进度条引用字段统一为 `barWidth/barHeight`，避免每帧重绘时宽高为 `undefined`。
  - 道路进度条补充 `当前/总进度` 文本，并与填充条同步刷新。
- 修复建筑/道路建造进度同步与跳变：
  - 建造进度不再直接使用全局 `timeProgress`。
  - 建筑和道路都按自身 `startTick + startTimeProgress` 计算进度，避免新建对象一放下就跳到当前 tick 中段。
  - 建造完成判定改为每帧推进，多个建造项独立计算时间。
- 修复缺少空闲工人时道路无法放置：
  - 道路现在允许先放置为等待建造状态。
  - 没有工人时建造进度停滞；出现空闲工人后自动分配并继续推进。
  - 道路存档补充 `workerAssigned/startTick/startTimeProgress`，避免读档后进度错误。
- 修复新手教程启用询问使用浏览器原生弹窗：
  - 新存档首次进入游戏时改用游戏内 `tutorial_prompt` 面板。
  - 面板提供“开启教程 / 暂时跳过”，选择前暂停游戏逻辑。
- 修复弹窗打开时背景音乐被暂停：
  - `AudioSystem` 不再把 `gamePaused/gameResumed` 作为 BGM 暂停/恢复条件。
  - BGM 现在只受静音、页面可见性和时段切换等音频预设条件影响。
- 修复入侵提示出现在开始菜单：
  - 删除 `#invasion-widget { display:flex }` 的默认显示覆盖规则。
  - `InvasionUI` 仅在存在活动入侵时添加 `active` 显示。
- 修复事件弹窗内容偏左：
  - 事件面板内容收窄并居中。
  - 事件描述和选项按钮文字居中。
  - `PopupManager` 切换面板前会重置 `popup-body` 内联样式，避免面板样式串场。

### 5. 新增功能与体验调整

- 开始菜单接入：
  - 使用 `config/ui_main_menu.json` 驱动主菜单。
  - “新游戏”会重置存档后进入游戏；“继续游戏”会加载现有存档。
  - 菜单 logo 即使配置为 `image`，只要有标题文字也会显示。
- 建筑建造渲染统一：
  - 动画贴图、静态贴图、文字回退三种建筑本体渲染后，统一进入建造渲染接口。
  - 建造显示效果统一为：目标建筑本体贴图/矩形 → 灰色遮罩 → 建造进度条。
  - 建筑名称渲染也收敛为共用方法。
- Ctrl 连续建造：
  - 放置建筑时按住 `Ctrl` 点击，可连续建造同一种建筑。
  - 默认点击仍保持原行为：成功放置后退出建造模式。
  - 每次连续放置仍逐次执行资源消耗、地块合法性和数量上限检查。
- 新手教程文档与任务提示更新：
  - `config/quests.json` 更新了道路缺工等待和 Ctrl 连续建造相关说明。
  - `docs/pages/新手教程.html` 补充开始菜单、建造遮罩进度、独立计时、道路等待工人等内容。
- 顶部 HUD 资源区重构：
  - 资源按“直接获取资源”和“加工转化资源”分组显示，但 UI 不直接暴露“一产/二产”字样。
  - 左侧资源组分别采用 `2x3` 和 `2x4` 网格。
  - 资源格内“图标 + 当前数量”左对齐，“新增/消耗速率”右对齐。
  - 资源格加宽，便于显示收益和消耗数字。
- 顶部 HUD 信息区重构：
  - 人口与陆/海军信息合并为一个竖向信息框。
  - 季节、天气、时段、日期和 tick 进度合并为一个时间天气框。
  - 视口中心坐标改为同一竖向框中分行显示 `X/Y`。
  - 设置按钮与全屏按钮改为上下堆叠，右侧信息区与左侧资源区底部对齐。
  - 顶部 HUD 背景改为纯色填充，减少透明浮层的杂乱感。
