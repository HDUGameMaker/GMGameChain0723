## 一、第五棒工作总览（10 个 Commit）

第五棒主要做了三大块：**炼金系统（全新）**、**人文政策树（从空壳做到完整）**、**驯养系统（驯敌部署）**，同时对战斗/资源/建筑/存档/UI 做了大量修补。

### 1. 炼金系统（AlchemySystem）—— 全新完整系统

- **系统文件**：`src/systems/AlchemySystem.js`（~888行）
- **UI 面板**：`src/ui/panels/alchemy-panel.js`（酿造界面，~500行）、`potion-inventory-panel.js`（药剂背包，~150行）
- **配置**：`config/alchemy.json`（319行：24种材料、25+配方、23种效果、5种盐、3种基底、5阶段Magnum Opus）
- **功能亮点**：
  - 实验发现引擎：材料元素×效力×基底偏差的加权评分 → Top-3 随机选择 → 品质阈值判定
  - 五盐辅助系统：虚空盐（返还材料）、月盐（成功率加成）、日盐（品质提升）、生命盐（额外产物）、贤者盐（加速酿造）
  - Magnum Opus 五阶段：Nigredo→Albedo→Citrinitas→Rubedo→哲人石
  - 炼金等级系统（1-10级）、材料库存、配方发现、研磨度（0~100归一化）
  - 药剂品质系统：品质元数据存于物品实例，UI 面板显示品质颜色
  - 精华精炼系统（config 配置消耗）
  - 建筑/探险产出炼金材料掉落
- **依赖注入**：炼金系统通过 `getEffects()` 将修饰器暴露给 CombatSystem/BuildingSystem/PopulationSystem

### 2. 人文政策树（CultureSystem）—— 从空壳到完整

- **系统文件**：`src/systems/CultureSystem.js`（~246行，框架参照 TechSystem）
- **UI 面板**：`src/ui/panels/culture-tree-panel.js`（~204行，第四棒只留了空壳）
- **配置**：`config/culture.json`（174行，多级政策/政体）
- **功能**：
  - 政策卡研究 + 激活（有切换冷却期 3 游戏日）
  - 政体选定（不可逆，与政策卡共享槽位）
  - Tier 0 自动解锁/激活
  - 效果聚合：economy（产量/建造成本）、combat（伤害倍率）、population（工人效率）
  - 效果通过 CultureSystem 接口分发给 CombatSystem/BuildingSystem/PopulationSystem

### 3. 驯养系统 —— 全新功能

- 在 CombatSystem 中新增 `tamed` 数组（驯化单位池）

## 二、仍存在的已知问题（Bug / 待办）

### 从第四棒遗留、第五棒未修完

1. **道路刷新 Bug**：刷新页面后道路可能消失，立即在同处放置道路会失败并吞材料（需先在别处放一个道路，再打开道路编辑器才能放）。
2. **建筑进度条闪烁**：右上角时间刻 +1 tick 时，建筑完成度会瞬间 +1 tick 然后复原（视觉效果，不影响实际进度）。
3. **敌方刷新位置不明**：敌方能正常刷新但不知道刷新到哪里去了，需排查 spawn 逻辑。
4. **设置面板快捷操作图标**：UI 图标未更新（第四棒遗留）。
5. **游戏名称**：还需要一个好名字（跨棒次持续征集）。

### 第五棒新引入的可能问题

6. 炼金系统与战斗/建筑/人口系统的修饰器链路较为复杂 — `AlchemySystem.getEffects()` → `CombatSystem._getCombatModifiers()` + `BuildingSystem` + `PopulationSystem` — 如果效果异常，先顺着这条链路排查。
7. 炼金和人文两套修饰器叠加时的优先级/乘法顺序未严格定义，极端情况下可能出现数值膨胀。
8. CultureSystem 的政策冷却（3 天）和政体不可逆逻辑已被实现，但 UI 面板的交互提示可能不够明确，玩家可能困惑。

## 五、关键系统依赖关系（第五棒新增后）

```
AlchemySystem ──修饰器──→ CombatSystem（药剂效果：伤害/攻速等）
                          BuildingSystem（药剂效果：建造速度等）
                          PopulationSystem（药剂效果：工作效率等）

CultureSystem ──修饰器──→ CombatSystem（政策效果：战士/弓箭手伤害倍率）
                          BuildingSystem（政策效果：建造成本/产出倍率）
                          PopulationSystem（政策效果：工人效率）

CombatSystem  ←── 同时接收两套修饰器叠加
```

修饰器叠加时以乘法叠算，注意排查异常数值。
