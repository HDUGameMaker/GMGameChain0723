活 动 规 则

⏱️

每棒限时 24 小时

从你接手项目的那一刻起算，24 小时内完成你的创作并交接给下一位。

🧱

在原有基础上继续

可以屏蔽前任的内容，但不能"完全推倒重做"——必须在已有成果上叠加。

🎨

想塞什么塞什么

玩法、美术、机制、剧情、配乐、UI、彩蛋……来者不拒，百无禁忌。

📦

必须交接

24h 到点必须移交项目，附交接说明（你做了什么 / 下个人可以往哪加）。

🧭

主题框架下自由发挥

主题由发起人给定（7.23 晚 8:00 直播公布），在主题框架内随意发挥。

🎮

共同游玩复盘

活动最后全体开发者上会游玩最终成品并复盘，之后发给社友们体验。

交 付 物 要 求

✅

可运行版本

哪怕是半成品也行，只要能打开看到效果即可。建议用 HTML 输出，一个浏览器就能跑。

📝

交接说明（Markdown）

列出本次提交做了哪些改动，让下一位快速了解项目当前状态。

💡

下棒建议（可选）

给下一个人提供创作方向，比如"这里可以加 BOSS 战"或"音效还缺"。自由选择是否给出。

参 与 准 备

🌐

浏览器

一个可以打开 HTML 文件的浏览器即可。

💻

IDE 编辑器

VS Code、记事本……任何你顺手的编辑器都行。

🤖

Vibecoding 工具

任意 Agent（Codex、Claude Code 等）+ 任意模型（DeepSeek、GPT、Claude 等）。不会？B站 15 分钟速成，或联系 miruo。

注 意 事 项

🔹 项目建议放在 Git 仓库里，每次交接前 commit 一次
🔹 大改动记得开分支，避免破坏主流程
🔹 别忘了吃早餐 🍳
🔹 出错了就重置回去重新来，反正没人评分
🔹 娱乐为主，别给自己太大压力
🔹 参考示例仓库：github.com/HDUGameMaker/ChainGameExample
🔹 提交时有疑问？联系哆啦A若（miruo）

活 动 奖 品

每位参与者选择一款游戏（CDK ≤ 50 元）填入奖池，填完后点击按钮随机分配，每人抽中一款。也可替换为等值现金。
