# 山体与采石区三层构图验收（2026-08-04）

## 修正结果

山体不再是“灰色方格上贴一张岩石图”。当前运行时统一采用三层构图：

1. `M`、`B` 山地与 `R` 裸岩地块使用森林树根下同源的浅黄土地基 `#C9AD7C`。
2. 每个山格绘制一块暖灰褐色 2.5D 大岩柱；主体宽度超过单格并压住相邻格线，使山群形成连续堆叠。
3. 相邻山格的右侧和下侧共享边界先绘制小碎石，再覆盖大岩柱，避免出现宽大的空白缝。
4. 森林、山体和碎石进入同一纵深排序：底脚行越靠下越接近镜头并覆盖后方对象；同一行按“碎石 → 山体 → 森林地表物”排序。

石料资源节点也取消灰色圆形徽章底座，改为浅黄土椭圆地基与同材质低矮石堆。固定地图的 `rock.png`、`rock1.png`、`stone.png`、`stone1.png` 继续兼容原路径，但画面已统一为新石堆。

## 运行时文件

- `src/rendering/MapPresentation.js`：统一黄土地基；稳定选择六种岩柱；生成相邻格碎石填缝模型；定义石矿节点黄土地基和地表物纵深值。
- `src/rendering/MapRenderer.js`：按底脚行统一排序森林、碎石和岩柱，并给石料节点绘制黄土底座。
- `assets/map/mountains/mountain_01.png` 至 `mountain_06.png`：六种大岩柱。
- `assets/map/mountains/stone_cluster_01.png` 至 `stone_cluster_03.png`：三种小碎石/低石堆。
- `assets/resource-nodes/stone.png`：石料资源节点图。
