# RTS × SLG 历史文明大重构设计

**日期：** 2026-08-03  
**状态：** 已批准，直接实施  
**运行基线：** `a6c804d`、64/64 Node 测试、121 个 JavaScript 文件语法通过、真实浏览器新游戏与存读档通过

## 1. 产品定位

游戏采用“帝国时代式基地经营与兵种组织”加“文明式时代、科研、人文、外交与大地图扩张”的混合结构。地图维持无缝方格战略地图，不模拟数百名士兵的逐人碰撞；玩家以建筑、人口岗位和军团为主要操控对象。

核心循环为：

1. 采集木头、石头、食物、黄金并发现奢侈品。
2. 建造聚落、生产、科研、人文、商业和军事建筑。
3. 把人口配置到建筑、农田、采集点和贸易岗位。
4. 研究当代科技与人文，选择具有差异的文明。
5. 招募武将与文臣，组建有限数量的军团。
6. 探索、贸易、驻防、征服城邦与野外据点。
7. 达成时代阈值后进入下一时代，并继承旧时代成果。

## 2. 不可破坏的运行约束

- 保持原生 ES Modules、PixiJS 8、GSAP 和 JSON 数据驱动，不引入构建步骤。
- 本地入口固定为 `启动游戏.bat` 与 `http://127.0.0.1:18763/`。
- 每个增量必须通过 `npm.cmd run check`。
- 关键流程必须通过真实浏览器验证：主菜单、新游戏、核心面板、保存、刷新、继续游戏。
- `MapRenderer` 只读取系统状态，不直接修改军团、建筑或资源系统状态。
- 四种基础资源始终只有 `wood`、`stone`、`food`、`gold`。
- 当前玩法不得出现炼金、法术、魔法等世界观词汇。

## 3. 七时代与文明

时代固定为：

1. `primitive` 原始时代：原始文明。
2. `ancient` 上古时代：周、亚述、新巴比伦、古埃及、古希腊、吠陀印度。
3. `classical` 古典时代：汉、罗马、帕提亚、贵霜、阿克苏姆、特奥蒂瓦坎、古典玛雅、邪马台。
4. `medieval` 中世纪：唐、阿拔斯、拜占庭、法兰克、盎格鲁-撒克逊、室利佛逝、加纳、平安日本、朱罗、托尔特克。
5. `exploration` 探索时代：明、奥斯曼、西班牙、葡萄牙、英格兰、荷兰、莫卧儿、阿兹特克、桑海、战国日本。
6. `early_modern` 近代：清、英国、法国、俄罗斯、普鲁士、美国、明治日本、奥斯曼改革、墨西哥、巴西。
7. `modern` 现代：中国、美国、俄罗斯、英国、法国、德国、日本、韩国、印度、巴西、尼日利亚、印度尼西亚。

同一时代不重复同一地区的前后王朝。每个非原始文明拥有：永久遗产、时代特色、特色单位、特色建筑、科技替换、人文替换、外交性格。

## 4. 科技树与人文树

两棵树使用相同的时代分页和节点密度：每时代八个基础节点，文明可替换一至两个节点。每个节点必须包含：

- `id`、`eraId`、名称、说明、历史背景、图标。
- 成本、研究 tick、前置节点。
- 至少一个运行时效果。
- 解锁建筑、单位、策略、阵型、贸易或城邦行动中的至少一项。

聚落提供每 tick 0.2 科技值和 0.2 人文值。对应建筑即使没有工作人员也会解锁树；实际产量主要来自建筑岗位。事件、遗迹、文明能力、英雄和外交协定可提供额外来源。

## 5. 经济、人口与建筑

人口可分配到建筑岗位、地图采集、农作物、贸易路线和驻军支援。所有岗位共享人口上限，不允许重复占用。

农田可以选择作物方案：谷物、豆类、果蔬、葡萄、棉花、亚麻、香料、甘蔗。基础产物仍结算为四资源或奢侈品，不新增第五种基础资源。

市场与商业中心建立城邦贸易路线。友好度、距离、道路、港口和敌对控制区影响收益与风险。资源转换由配方驱动，并受每日上限约束，避免无限套利。

邻接系统扩展为半径光环：配置适用建筑标签、效果、半径、最大叠加和视觉范围。纪念碑、寺庙、广场、花园等必须提供实际人文、满意度、贸易或生产效果。

## 6. 军团、移动与战斗

军团是地图上的主要友方战斗实体。军团状态包含：

- 坐标、路径、移动力、领域、当前命令。
- 前排、远程、侧翼、工程、特殊、海军单位栈。
- 武将、阵型、最多两张战争策略。
- 补给、士气、侦察、驻扎位置和伤员。

军团基础上限为 2；指挥所、战争议会、营寨、要塞与大城堡提高上限或提供驻军槽。陆军可在码头登船，在水上受到运输惩罚；专职舰队没有该惩罚。

战斗分为侦察、远程、侧翼、正面、工程、溃退六阶段。计算使用兵种克制、地形、补给、士气、阵型、策略、武将技能和时代差。界面展示阶段战报和关键修正来源。

## 7. 城邦、野外据点与外交

城邦数量目标为 12。城邦没有完整玩家建设树，但拥有随玩家时代滞后升级的驻军模板、固有效果和少量特色能力。城邦之间维护简化关系矩阵并触发贸易、争端、结盟和战争事件。

外交行动包括交谈、赠礼、援助、通商、互不侵犯、军事通行、联盟、威胁、宣战、议和、附庸和征服。行动由关系值、信誉、人文节点、英雄、军力差和历史事件共同决定。

蛮族营地、海盗港、遗迹守卫和野外资源点使用独立的野外据点系统，不伪装成城邦。

## 8. 英雄

英雄明确分为：

- `military` 武将：只能配置给军团，拥有战斗阶段触发技能。
- `civil` 文臣：配置给建筑、聚落职位、贸易路线或外交任务。

目标英雄数量为 72，覆盖上古至现代。酒馆提供当前及所有旧时代尚未招募的英雄。英雄失败后进入伤病恢复，不永久删除。

## 9. 美术与音频

- 所有可研究科技、人文、单位、建筑、策略、阵型均有图标。
- 至少 137 个兵种拥有独立 2.5D 俯视展示图。
- 约 72 名英雄拥有独立头像。
- 建筑拥有菜单图标和地图图标；地图显示染色占地、图标和名称。
- 建筑悬停卡显示岗位、产出、光环、状态和升级方向。
- 军团、舰队、城邦、营寨和海盗据点拥有地图图标。
- 七个时代各有一首原创循环 BGM，切换时代时交叉淡入淡出。
- 音效覆盖建造、研究、招募、移动、交战、外交、胜利和失败。

批量图像通过 assetify/generate2dsprite 工作流生成、切片、去边和验证。音乐在无外部音乐生成器时使用本地可复现的原创合成脚本生成。

## 10. 存档与迁移
