# 历史文明全系统重构设计

## 1. 目标与核心循环

游戏定位调整为无魔法的历史文明经营、扩张与战争游戏。核心循环为：在无缝地图采集四种基础资源，建设城市并分配人口，研究当代科技与人文，选择文明传统，训练分时代军队，探索和争夺奢侈品，与城邦外交或战争，完成时代目标后进入下一时代，最终通过征服、文化、科技或联盟取得胜利。

所有新增系统必须服务于“建设—分工—研究—扩张—选择时代文明”循环。炼金、药剂、法术、驯养等魔法口吻和入口退出活动玩法；原有可用效果转写为一次性策略卡。

## 2. 时代与文明

采用七个时代，每时代八个可选文明，共 56 个历史文明：

1. 远古时代：华夏部落、苏美尔、古埃及、印度河、米诺斯、阿卡德、赫梯、奥尔梅克。
2. 古典时代：汉、罗马、波斯、孔雀王朝、雅典、斯巴达、迦太基、玛雅。
3. 中世纪：唐、法兰西、英格兰、拜占庭、阿拔斯、蒙古、德里苏丹国、阿兹特克。
4. 探索时代：明、西班牙、葡萄牙、奥斯曼、威尼斯、荷兰、莫卧儿、印加。
5. 工业时代：大清、法兰西帝国、大英帝国、普鲁士、俄罗斯帝国、美国、明治日本、墨西哥。
6. 现代时代：中国、美国、苏联、英国、法国、德国、印度、日本。
7. 信息时代：中国、美国、欧盟、印度、日本、韩国、巴西、非洲联盟。

每个文明提供一个永久遗产、一个本时代特色、一个特色单位和一个特色建筑替代项。进入下一时代时文明选择改变当前特色，但所有已获得的文明遗产永久保留，以形成跨时代组合。

时代推进要求完成当前时代至少 70% 的科技节点、70% 的人文节点，并取得足够时代星。时代星来自人口、领土、建设、探索、外交、战斗和奢侈品目标。

## 3. 经济与人口

### 四种基础资源

- 木材：地图森林直接采集；建筑、弓兵、舰船和攻城器械的主要成本。
- 石材：地图岩地直接采集；防御、行政和大型建筑的主要成本。
- 食物：地图平原、水域沿岸直接采集；人口维持与所有作战单位训练的主要成本。
- 黄金：地图金脉、市场和贸易直接获得；高级单位、英雄、外交、研究和复杂建筑的通用成本。

基础资源继续由 `ResourceSystem` 管理并显示在 HUD，不增加第五种基础资源。

### 二十种奢侈品

奢侈品为独立库存，不进入基础资源栏：丝绸、玉石、茶叶、香料、象牙、香料酒、葡萄酒、熏香、宝石、珍珠、琥珀、毛皮、染料、可可、咖啡、瓷器、香水、银器、马匹、盐。每种奢侈品绑定地图产地、开发建筑、持有数量与帝国效果；首份提供满意度和特色效果，重复份用于贸易。效果覆盖人口增长、生产、研究、文化、外交、陆战、海战、英雄和策略卡。

### 人口岗位

人口恢复为核心资源。人口由住房容量、食物结余、满意度和时代修正共同决定。每日每人消耗食物，缺粮降低满意度并造成迁出，长期严重缺粮才死亡。

建筑具有 `maxWorkers` 和岗位类型。零工人建筑只提供“解锁类”被动，不产出点数或资源；工人数按线性基础效率叠加熟练度与满意度修正。学院零工人仍解锁科技树，但不产生科技点；人文建筑同理。建设、探索和军队也占用人口，HUD 展示总人口、空闲、生产、研究、军役与住房。

## 4. 建筑体系

建筑按九类组织：住宅、采集、储存、研究、人文、军事、海军、商业、行政与防御。目标运行时不少于 32 个有独特用途的建筑。

关键建筑包括：住宅、庄园、伐木场、采石场、农田、金矿、仓库、粮仓、学院、图书馆、人文馆、纪念碑、市场、商栈、酒馆、工坊、铁匠铺、军营、靶场、马厩、攻城工坊、城堡、城墙、瞭望塔、码头、造船厂、灯塔、港口、议政厅、法院、使馆、奢侈品工坊。训练建筑决定兵种分支；学院和人文馆决定双树研究；市场与商栈处理奢侈品贸易；城堡兼具防御、驻军和精英单位能力。

## 5. 科技树、人文树与兵种页

科技树和人文树结构对称：每时代各八个节点，按两行四列分页显示。科技点由学院、图书馆和科技型英雄产生；人文点由纪念碑、人文馆、议政厅和文化型英雄产生。研究消耗对应点数并随 tick 推进，跨时代节点在时代未解锁前不可研究。

每时代拥有一页通用兵种，按近战、远程、骑兵、工程、特殊和海军分类。单位包含时代、领域、训练建筑、人口占用、升级来源、克制标签和历史说明。文明特色单位在选择对应文明后加入当代页。旧兵种不会删除，可继续训练但相对新兵种战力会逐时代落后。

## 6. 战斗、海战与城邦

战斗采用准备—部署—三线交战—士气结算：前线承受近战，后线输出远程，侧翼由骑兵争夺，攻城单位针对建筑，海军只在水域作战。伤害由战力、克制、阵型、地形、英雄、补给和士气共同决定。长枪克骑兵、骑兵克远程、远程压制步兵、盾兵克远程、攻城克建筑、轻兵克攻城；海军中火船克重舰、重舰克桨帆舰、桨帆舰克运输与远程舰。

第 10 天开始生成城邦式 NPC。它们拥有小型核心据点、有限特殊建筑和少量特色单位，不运行玩家完整双树。关系状态包括敌对、警戒、中立、友好、盟友与附庸；支持交谈、赠礼、贸易、任务、开放边界、驻军援助、联合战争、威慑、勒索、停战和征服。征服后据点保留并转为附属地。

胜利包括：占领全部敌对核心的征服胜利、完成末代科技工程的科技胜利、集齐跨时代遗产与人文节点的文化胜利、建立城邦联盟的外交胜利。大本营失守或人口归零为失败。

## 7. 英雄与策略卡

英雄按时代池出现，酒馆每三日刷新四名当前或更早时代英雄。英雄永久拥有；战败进入受伤倒计时，结束后自动复归。英雄可任命为总督、统帅、学者、使节、工程师或探险家，提供范围和岗位效果。至少 35 名英雄覆盖七时代。

策略卡完全替代法术：军事动员、区域增产、紧急征税、加速研究、工程抢修、封锁航道、散布谣言、冻结敌方推进倒计时等。卡牌由任务、时代星、事件、英雄和城邦奖励获得，使用后进入弃牌或冷却。所有名称、描述、图标和反馈均使用历史策略口吻。

## 8. 地图与美术

地图保持 200×200 无缝网格。可玩区域水面占比目标为 20%–25%，默认 22%；水系由海湾、湖泊和多条相互连通的河流组成，区分浅水与深水。陆地保留草地、土地、森林、岩地和山脉。码头必须临浅水，重型舰船需要深水通路。

科技、人文、文明、兵种、英雄、建筑、奢侈品和策略卡全部拥有图标。视觉规范为历史大战略游戏：深色羊皮纸底、金属描边、低饱和矿物色、清晰剪影、无现代扁平表情符号依赖。批量内容使用统一图标图集与可追踪清单，缺图时使用类别专属 SVG 兜底，不显示空白。

## 9. 架构、存档与兼容

新增 `historical_content.json` 作为大规模内容配置，运行时由 `ConfigRegistry` 按 ID 合并；主配置同 ID 优先。新增 `EraSystem`、`LuxurySystem` 和 `StrategySystem`，分别独占时代文明、奢侈品、策略卡状态。旧 `AlchemySystem` 和 `SpellSystem` 不再初始化、保存或展示，但 v6 存档中的字段允许忽略。

存档升级到 v7。v6 读取时恢复既有资源、建筑、部队、外交和英雄；人口为 0 时迁移到新游戏最低人口；新增时代、文明遗产、科技点、人文点、奢侈品和策略卡字段采用安全默认值。配置与存档中仍只允许基础成本引用四种资源。

## 10. 验收标准

- 运行时基础资源恰好四种，奢侈品恰好二十种且均有实际效果。
- 人口、住房、食物消耗和建筑岗位形成闭环；学院/人文馆零工人不产点数。
- 七时代、每时代八文明、每时代八科技与八人文节点可分页查看并受时代门槛限制。
- 运行时建筑不少于 32、单位不少于 70、英雄不少于 35、策略卡不少于 20，全部具有图标路径或可靠兜底。
- 地图水面占可玩区域 20%–25%，浅水/深水连通并可训练、部署海军。
- 第 10 天出现有限发展城邦，外交、战争、征服和胜负状态可存档恢复。
- 不再存在玩家可见的炼金、法术、药剂或驯养入口与文案。
- v6 存档可迁移到 v7；自动化测试、语法检查、配置一致性检查和浏览器主流程回归通过。
