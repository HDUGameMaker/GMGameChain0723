# 参考图岩山三层构图设计

## 目标

在方格大地图中复现参考图的视觉逻辑，而不是粘贴完整山体贴图：浅黄土是地表，大岩块像树木一样作为独立主体相互压叠，小碎石填补主体之间的窄缝。

## 构图规则

- 地基：山脊 `M`、山麓 `B`、裸岩 `R` 使用 `#C9AD7C`，与森林素材树根下的浅黄土一致。
- 主体：每格一座透明大岩柱，山脊画布宽度约 1.48 格，山麓约 1.26 格；越格仅用于视觉压叠，不改变碰撞与地形判定。
- 填缝：相邻山格的右边和下边生成稳定的小碎石模型，先于主体绘制；碎石跨过共享格线。
- 层次：按行从上到下绘制主体，使下方岩块自然覆盖上方岩块底缘，形成 2.5D 堆叠关系。
- 跨类型遮挡：森林地表物与山石共享同一纵深序列；底脚行更大的对象位于前景。同一行的森林高于山体越格部分，山体高于碎石。
- 石矿：固定裸岩与资源节点使用相同岩石材质；资源节点采用黄土椭圆底座，不使用灰色圆形徽章。

## 稳定性与玩法边界

所有素材变体由坐标哈希稳定选择，重载地图不会随机跳变。此改动只影响显示，不改变山地通行、洞穴、石矿储量、采集建筑放置与资源产出规则。

## 验收

- 山地、裸岩与石矿节点均无灰色方块或灰色圆底。
- 连续山格的大岩柱越格压叠，窄缝存在碎石，外围可见浅黄土地基。
- 前景树木覆盖后景山石，不会再被后添加的整层山体反向遮挡。
- 浏览器截图同时展示山群与低矮采矿石堆。
- Node 测试、JavaScript 语法检查及 Chromium 冒烟测试全部通过。
