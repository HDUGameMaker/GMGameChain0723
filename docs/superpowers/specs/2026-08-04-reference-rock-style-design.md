# 参考图岩柱与采矿石块统一设计

## 目标

把地图上的山体、裸露矿岩和石料采集点统一为用户参考图中的暖灰褐色 2.5D 岩石风格：大块直立岩柱具有宽顶面、纵向岩面、深色轮廓和裂纹，基部由小碎石围绕。运行时不再显示白色石块、黑色洞形贴图或程序绘制的几何小石头。

## 视觉资产

使用参考图生成一个 3×3 紧凑地图道具包。前两行提供六个独立高岩柱变体，第三行提供三个较低的采矿石堆变体。所有格子保持同一暖灰褐调、左上方柔光、深灰描边和手绘策略游戏材质；背景必须是纯 `#FF00FF`，每个道具完整留在格内且互不接触。

处理后交付：

- `assets/map/mountains/mountain_01.png` 至 `mountain_06.png`
- `assets/map/mountains/stone_cluster_01.png` 至 `stone_cluster_03.png`
- 旧地图入口 `assets/map/rock.png`、`rock1.png`、`stone.png`、`stone1.png` 替换为同一资产族，保证固定地图配置无需重写。
- `assets/resource-nodes/stone.png` 替换为透明背景采矿石堆，不再带蓝黑卡片底框或白色方石。

## 地图渲染

`MapPresentation` 只负责根据地形代码和格子坐标稳定选择岩柱变体、尺寸与位置。山麓 `B` 使用略低尺寸，山脊 `M` 使用接近完整格高的岩柱；每格只显示一座主岩柱，资产自身携带基部碎石，整片相邻山格组合成参考图式山群。

`MapRenderer` 预加载六个山体变体并以 Sprite 绘制，不再运行多边形岩块绘制。岩柱限定在所属方格内，仍保留地形格底色、网格边界、山地不可通行、洞穴入口与矿点交互。

裸露矿岩 `R` 继续走固定地图的地形纹理路径，但四张旧纹理均替换为新资产。石料资源点继续由 `ResourceNodeSystem` 管理，只替换视觉，不改变储量、采集建筑、占领或产出规则。

由于旧 `R` 地形底色为白色 `#dedede`，透明石堆会暴露白色方格；运行时将其覆盖为暖灰褐 `#756b5e`，与参考岩石底部阴影和碎石颜色协调。

## 验收

- 山地模型只返回新 `assets/map/mountains/` 路径，坐标选择可复现。
- 山麓与山脊尺寸不同，但均不越出所属格。
- 四张旧裸岩入口和石料资源点图均为透明背景暖灰褐岩石，不再包含白色主体或卡片边框。
- 浏览器截图同时展示大型山群和石料节点，二者材质、光向、描边和碎石语言一致。
- Node 全量测试、JavaScript 语法检查及 Chromium 冒烟测试通过。

## 并行修改保护

不修改或暂存 `config/historical_content.json`、`assets/map/generated/`、`tmp/` 以及当前并行进程维护的其他配置文件。固定地图的旧纹理路径通过替换对应二进制资产保持兼容。
