# 文明特色建筑与时代推进修复设计

## 目标

1. 57 个文明继续各自拥有一个主要特色建筑，但按历史定位分布到全部 11 个正式建筑类别，而不是只集中在科技与人文。
2. 特色建筑的类别必须对应可运行的建筑功能：住房提供人口容量，科研/人文提供点数，军事/海军提供训练与容量，商业/工业/农业产生资源，防御提供驻军能力。
3. 新游戏和旧存档都能通过正常游玩获得时代星，并从原始时代持续推进到现代。
4. 修复教程任务中的失效建筑引用，并为教程探索提供出生点附近的山洞入口。

## 数据边界

- `config/historical_content.json`、`assets/map/generated/` 与 `tmp/` 由另一个进程维护，本任务只读且不提交。
- 新建 `config/civilization-building-overrides.json` 作为运行时覆盖层；它只按文明 ID 修改内存中的特色建筑记录。
- 新建 `config/campaign-progression.json` 保存时代星奖励数值，避免在 JavaScript 中硬编码平衡参数。

## 文明建筑分类

覆盖层使用正式建造菜单的 11 类：`housing`、`agriculture`、`gathering`、`industry`、`commerce`、`research`、`civic`、`military`、`defense`、`naval`、`administration`。

目标分布为：住房 1、农业 1、采集 1、工业 8、商业 9、科研 7、人文 9、军事 6、防御 6、海军 3、行政 6。每类至少一个，任何单类不超过 9 个。

类别由建筑本身的历史用途决定。例如智慧宫与国家理工学院属于科研，王家兵工场与总参谋部属于军事，皇家交易所与黄金商站属于商业，狄奥多西城墙与马奇诺要塞属于防御，宝船厂与皇家船坞属于海军，大型联合工厂与官营制铁所属于工业。

## 时代里程碑

每个时代的时代星来自可追溯且不可重复的里程碑：

- 选择当代文明：1 星。
- 每完成一个当代科技：1 星。
- 每完成一个当代人文：1 星。
- 科技达到 70%：额外 2 星。
- 人文达到 70%：额外 2 星。
- 建成当代文明特色建筑：3 星。

完成两棵树的最低晋升比例、选择文明并建成特色建筑时可稳定获得 20 星，足以满足最高的近代→现代晋升要求；不建特色建筑的玩家也可通过完成更多研究取得同等进度。

里程碑 ID 进入 EraSystem 存档。`canAdvance()` 会根据当前研究和建筑状态进行一次幂等补算，因此已有研究但时代星为 0 的旧存档可以恢复，不要求玩家重新研究。

## 教程可达性

- `tutorial_food` 改为要求现有的 `hunting_lodge`。
- 固定地图生成器优先保留距离出生点最近的合格山洞入口，并要求曼哈顿距离不超过 25 格；其余入口继续分布到大型山体。
- 教程仍要求道路连接洞口，但不再要求跨越上百格地图。

## 验证

- 配置覆盖测试检查 57 个文明、11 类分布、替代目标与真实功能。
- 教程契约测试检查全部建筑引用存在、入口距离可行。
- 完整时代模拟循环选择文明、补齐研究、建成特色建筑并连续晋升六次直至现代。
- 运行全量 Node 测试、语法检查和 Playwright 浏览器冒烟；真实浏览器检查时代面板、建造菜单和控制台。
