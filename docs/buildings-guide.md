# 游戏建筑指南

本文档详细介绍了游戏中的所有建筑，包括建筑的名字、ID、用处、解锁条件、功能等信息。

## 建筑分类

游戏中的建筑按照功能和升级链分为以下几类：

| 分类 | 标签 | 包含建筑 |
|------|------|----------|
| 🏠 宿舍系 | dorm | 工棚、木板房、瓦房、砖房 |
| 📦 仓库系 | warehouse | 仓库、工业仓储中心、钢铁仓储中心 |
| ⛏️ 采场系 | stope | 采场、进阶采场、高阶采场 |
| 🌲 伐木集散点系 | logging_camp | 伐木集散点、进阶伐木集散点、高阶伐木集散点 |
| 🏭 木材厂系 | lumber_mill | 木材处理厂、进阶木材处理厂、高阶木材处理厂 |
| 🔥 锻造坊系 | forge | 锻造坊、进阶锻造坊、高阶锻造坊 |
| 🛠️ 工作站系 | workshop | 基础工作站、进阶工作站、精密工作室 |
| 💡 火把系 | torch | 火把、强化火把、超级火把、永恒火把 |
| 🐟 渔场系 | fishing_ground | 渔场、进阶渔场、高阶渔场 |
| 🦌 狩猎场系 | hunting_ground | 狩猎场、进阶狩猎场、高阶狩猎场 |
