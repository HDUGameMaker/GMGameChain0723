# 《文明纪元》数值与平衡基线

本文件记录 0.7.0 的平衡检查入口，供后续数值迭代使用。完整对象数据以 `config/historical_content.json`、`config/buildings.json`、`config/enemies.json` 和 `config/ea_integration.json` 为准。

## 1. 开局基线

| 项目 | 数值 |
|---|---:|
| 木头 | 150 |
| 石头 | 100 |
| 食物 | 100（事件和日结会改变） |
| 黄金 | 50 |
| 初始人口 | 12 |
| 初始住房 | 16 |
| 初始满意度 | 60 左右 |
| 初始军役容量 | 3 |

建议前 10 天目标：建立稳定食物净产出、至少一个研究岗位、一个人文岗位和基础训练设施，并在城邦激活前完成一次外围侦察。

## 2. 时代推进基线

| 时代 | 下一时代星要求 | 科技完成 | 人文完成 |
|---|---:|---:|---:|
| 远古 | 5 | 70% | 70% |
| 古典 | 8 | 70% | 70% |
| 中世纪 | 11 | 70% | 70% |
| 探索 | 14 | 70% | 70% |
| 工业 | 17 | 70% | 70% |
| 现代 | 20 | 70% | 70% |
| 信息 | 最终时代 | — | — |

每时代科技和人文各 8 项。70% 实际意味着至少完成 6 项，避免要求全点满，同时保持两树权重一致。

## 3. 建筑岗位原则

| 建筑方向 | 零工人 | 加派工人 |
|---|---|---|
| 资源建筑 | 不生产或仅保留极低基础功能 | 线性或按配置提高产量 |
| 学院 | 解锁科技树 | 生产科技点 |
| 人文大厅 | 解锁人文树 | 生产人文点 |
| 市场 | 保留交易入口 | 提升交易或黄金收益 |
| 军事建筑 | 保留解锁/容量功能 | 按配置提高训练或支援效率 |
| 酒馆 | 提供英雄入口 | 当前设计不占岗位 |

平衡时优先调整配置中的 `maxWorkers`、岗位产出、建造成本和建造时间，不应恢复自动填满岗位。

## 4. 兵种克制矩阵

| 进攻方 | 优势目标 | 主要弱点 |
|---|---|---|
| 近战步兵 | 轻步兵、弓弩 | 骑兵、穿甲、炮兵 |
| 远程部队 | 慢速步兵、长兵器 | 骑兵、装甲单位 |
| 反骑兵 | 骑兵、部分装甲 | 远程火力、炮兵 |
| 骑兵 | 远程、攻城、轻装 | 长兵器、火器、反装甲 |
| 攻城器械 | 建筑、工事、密集阵形 | 机动近战、骑兵、空中单位 |
| 特殊部队 | 依单位定义承担侦察、空中或合成作战 | 补给消耗与专项反制 |
| 轻型舰艇 | 运输舰、袭扰目标 | 重舰和火攻 |
| 重型舰艇 | 中型舰艇、沿岸工事 | 火攻、空中、舰群 |
| 火攻舰 | 重型和中型舰艇 | 轻舰、远程舰艇 |

每个单位同时受时代、训练建筑、专项研发、人口、资源和文明归属约束。不得仅按 `combatPower` 排序判断实际强度。

## 5. 城邦压力基线

- 第 10 天激活。
- 敌对或警惕关系每 3 天尝试扩张。
- 单个城邦最多控制 12 格。
- 中立会停止扩张；友好与同盟提供更稳定的互动收益。
- 城邦不是玩家同级文明，不研究完整双树或自行选择文明。

测试重点应比较三条路线的总收益：早期征服、维持中立、长期结盟。若某一路线始终最优，应调整战争损耗、贸易收益、条约门槛和征服奖励。

## 6. 奢侈品与策略

- 奢侈品首份效果应保持“可感知但不决定胜负”。
- 重复品价值由黄金收益与外交关系共同构成，避免只等同于黄金矿。
- 策略卡是稀缺消耗品，初始只提供少量基础策略。
- 持续策略必须有明确时长或冷却，不能形成永久无成本增益。

## 7. 建议测试场景

1. 远古 20 天纯经济发展。
2. 远古 20 天早期军事扩张。
3. 第 10—30 天与城邦的敌对、中立、同盟三路线对照。
4. 无奢侈品与拥有 3 种奢侈品的成长曲线对照。
5. 单一兵种与混编军队对同一防御目标的战损对照。
6. 内陆发展与尽早建立码头的机会成本对照。
7. 每个时代完成 70% 双树所需现实时间和游戏日数。

所有平衡改动后执行 `npm run check`，并至少完成一次新游戏和一次旧存档迁移的浏览器验收。
